# VPN Казахстан → ОАЭ (MVP)

## Что делаем

Пользователь в ОАЭ подключается к VPN-серверу в Казахстане. После подключения сайты и сервисы видят казахстанский IP-адрес.

```text
Телефон / ноутбук в ОАЭ
          │
          │ WireGuard (зашифрованный туннель)
          ▼
VPN-сервер в Казахстане
          │
          ▼
Казахстанские сайты и сервисы
```

Для MVP используем:

- Ubuntu Server;
- WireGuard;
- Ansible прямо на сервере;
- без Docker, панели управления и базы данных.

## Проверенный сервер

Сервер проверен 6 августа 2026 года:

- Ubuntu 24.04.4 LTS;
- 1 CPU;
- 961 МБ оперативной памяти;
- диск 20 ГБ: занято 3,3 ГБ, свободно 16 ГБ;
- публичный IPv4: `78.40.108.74`;
- Ansible Core 2.16.3 установлен.
- WireGuard работает на UDP-порту `443`;
- для клиента используется MTU `1280`;
- BBR и очередь `fq` включены.

Для простого VPN 20 ГБ достаточно. После установки Ansible, обновлений и WireGuard занято только 18% диска.

Ориентировочный расход места:

- Ubuntu: 4–7 ГБ;
- обновления и служебные файлы: 2–4 ГБ;
- Ansible и WireGuard: меньше 1 ГБ;
- запас: около 8 ГБ или больше.

Сам VPN почти не хранит данные. Место могут занять старые обновления и логи, поэтому настроим очистку логов и будем проверять диск командой `df -h`.

## Как это будет работать

1. ✅ Подключились к серверу по SSH.
2. ✅ Проверили Ubuntu, диск, память и публичный IP.
3. ✅ Установили Ansible на сервер.
4. ✅ Ansible установил и настроил WireGuard.
5. ✅ Включили пересылку трафика и NAT.
6. ✅ Открыли только SSH и UDP-порт WireGuard.
7. ✅ Создали отдельный конфиг для первого клиента `client1`.
8. Проверяем подключение из ОАЭ и доступ к нужным сайтам.

## Как подключиться

1. Установите приложение WireGuard на телефон или компьютер.
2. Импортируйте файл `clients/client1.conf`.
3. Включите туннель.
4. Найдите в браузере «мой IP» и проверьте, что показывается IP `78.40.108.74` и Казахстан.

Один конфиг используйте только на одном устройстве. Для следующего пользователя создайте новый конфиг.

## Важные проверки до запуска

- IP сервера действительно определяется как Казахстан.
- Провайдер разрешает VPN и UDP-трафик.
- Нужные государственные сайты открываются с IP сервера.
- Kinopoisk работает с этим IP. VPN меняет IP, но не гарантирует доступ: сервис может блокировать дата-центры или учитывать условия подписки.
- Использование сервиса соответствует законам ОАЭ, Казахстана и правилам сайтов.

## Что не делаем в первой версии

- не ставим Docker;
- не храним историю посещений;
- не делаем личный кабинет и оплату;
- не выдаём один конфиг нескольким людям.

Сначала запускаем 2–5 тестовых пользователей. Если всё работает стабильно, добавляем автоматическую выдачу и отзыв клиентских конфигов, мониторинг и резервный сервер.
